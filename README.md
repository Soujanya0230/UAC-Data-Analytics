# UAC System Capacity & Care Load Analytics

## Project Overview
This project focuses on analyzing the Unaccompanied Alien Children (UAC) Program dataset to understand care workload, custody trends, transfers, and discharges over time.

The objective is to transform raw data into meaningful insights using Python, data cleaning, statistical analysis, and data visualization.

## Objectives
- Analyze yearly and monthly trends in UAC program data.
- Understand changes in care workload over time.
- Examine trends in HHS care and CBP custody.
- Identify peak workload periods.
- Generate meaningful summaries and visualizations to support data-driven insights.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Data Visualization
- Exploratory Data Analysis (EDA)

## Dataset
**Dataset:** `HHS_Unaccompanied_Alien_Children_Program.csv`

The dataset is used to examine historical trends related to the UAC program.

## Project Workflow

### 1. Data Cleaning & Preprocessing
- Loaded the raw dataset using Pandas.
- Examined data structure and data types.
- Handled missing and inconsistent values where required.
- Prepared the dataset for analysis.

### 2. Exploratory Data Analysis (EDA)
- Performed statistical analysis using NumPy and Pandas.
- Examined yearly and monthly trends.
- Analyzed care and custody patterns.
- Identified peak workload periods.

### 3. Data Visualization
Created visualizations to understand the data more effectively:

- HHS Care Trend
- CBP Custody Trend
- Yearly Comparison
- Monthly Transfers & Discharges
- Peak Workload Analysis

### 4. Data Export
Generated analytical output files for further reference:

- `Cleaned_UAC_Data.csv`
- `UAC_Yearly_Summary.csv`
- `UAC_Monthly_Summary.csv`
